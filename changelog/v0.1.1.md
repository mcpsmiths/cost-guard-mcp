# v0.1.1 — 2026-09-13

### Added

- Documentation: `AGENTS.md`, `CLAUDE.md`, `ARCHITECTURE.md`, `DECISIONS.md`, `CONTEXT.md`,
  `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`.
- `.github/ISSUE_TEMPLATE/` (YAML forms) and a pull request template.
- Verified config snippets for Claude Code, Cursor, OpenAI Codex CLI, and GitHub Copilot,
  plus a single canonical `.mcp.json.example`.
- `mypy` type checking in CI.
- CodeQL and OpenSSF Scorecard workflows.
- `dependabot.yml` (native `uv` ecosystem + `github-actions` updates).
- Dependency vulnerability scanning (`uv export` → `pip-audit`).
- `release.yml`: automated PyPI publish via Trusted Publishing (OIDC), CycloneDX SBOM
  generation, and automatic GitHub Release creation on a version-tag push.
- `.pre-commit-config.yaml` and `.coderabbit.yaml`.

### Fixed

- `explain_estimate` (Snowflake engine) now raises a clear error if `EXPLAIN USING JSON`
  unexpectedly returns no rows, instead of an opaque `TypeError` from indexing into `None`.

### Security

- Enabled ruff's `S` (flake8-bandit) rule set; the two real hits were both intentional
  caller-SQL wrapping (documented with `noqa`), not actual vulnerabilities.
- Enabled GitHub secret scanning, push protection, and Dependabot security updates at the
  repo level (all were off despite being free for public repos).
- Enabled branch protection on `main` requiring CI to pass.
- PyPI releases no longer use a stored API token — publishing now happens via Trusted
  Publishing (OIDC) with no credential stored anywhere.
