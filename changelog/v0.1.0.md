# v0.1.0 — 2026-09-12

Initial release.

### Added

- `describe_engine_capabilities(engine)`, `estimate_query_cost(engine, sql, warehouse?)`,
  `run_query_bounded(engine, sql, max_bytes_billed?, max_rows?, max_estimated_cost_usd?)`.
- BigQuery engine: `PRECISE` cost estimates via `dryRun`, with automatic downgrade to
  `UPPER_BOUND` when BigQuery's own accuracy field is non-precise, and correct handling
  of Editions/capacity-billed projects (byte estimate only, no dollar figure).
- Snowflake engine: `UPPER_BOUND` cost estimates via `EXPLAIN USING JSON`, key-pair
  (`SNOWFLAKE_JWT`) authentication preferred over password auth.
- Credential-redacting exception sanitizer wrapping every warehouse client call.
- Wire-safe row capping (`LIMIT max_rows + 1` subquery) — never fetches more than the
  cap to enforce it.
- CI: secret-free unit-test workflow on every push/PR; a separate gated
  `workflow_dispatch`/scheduled live-integration workflow for both engines.

### Security

- Fail-closed cap checks: a requested cap with no matching estimate field refuses rather
  than running unbounded.
- Identifier validation before string interpolation into a query-language context
  (Snowflake warehouse names, GCP project IDs) — closes two real injection surfaces found
  during development and live testing.
- Snowflake role has no default and is never `ACCOUNTADMIN`.

### Known limitations

- Databricks not yet supported.
- Snowflake's `UPPER_BOUND` estimate excludes Cortex AI Function ("AI Credits") cost.
- BigQuery Editions/capacity-billed projects get a byte estimate only, no dollar figure.
