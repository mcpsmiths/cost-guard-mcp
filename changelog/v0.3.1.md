# v0.3.1 — 2026-09-22

Metadata-only patch. Found via a third-party MCP marketplace listing
(mcp-marketplace.io) that indexes this server from the official MCP Registry and runs
its own automated package-verification scan against the published PyPI artifact.

### Fixed

- `pyproject.toml` had no `[project.urls]` section, so the published PyPI package page
  had no link back to this GitHub repository — confirmed directly via
  `https://pypi.org/pypi/cost-guard-mcp/json`, whose `info.project_urls` was `null`. A
  marketplace scanner flagged this as an Info-severity "package-verification" finding
  ("PyPI package has no GitHub URL"). Added `Homepage`, `Repository`, `Issues`, and
  `Changelog` links.

### Investigated, not changed

- The same marketplace listing tags several `server.json` `environmentVariables`
  entries "Required" and others "Optional" in a way that looked inconsistent with the
  README's actual conditional requirements (e.g. it marks `SNOWFLAKE_PRIVATE_KEY_PATH`,
  `SNOWFLAKE_PRIVATE_KEY_PASSPHRASE`, *and* `SNOWFLAKE_PASSWORD` all "Required"
  simultaneously, when in reality only one of the first or third is needed). Confirmed
  via a real browser session against the live page: this badge tracks this project's own
  `isSecret` field exactly (every "Required"-tagged variable has `isSecret: true` in
  `server.json`; every "Optional"-tagged one does not) — it is the marketplace's own
  display choice, not something `server.json` controls directly, and not something this
  project should "fix" by marking a real secret as non-secret. No change made.
